# Student Marks Calculator — HTML, CSS & JavaScript

A responsive beginner-friendly web project. Enter a student's name and marks in five subjects to calculate total marks, percentage, grade, and pass/fail status.

## Features
- Responsive layout for desktop and mobile
- HTML form with input validation
- JavaScript calculations and grade assignment
- Visual progress bars for each subject
- Clear form and print result options
- No frameworks or external JavaScript libraries

## Files
- `index.html` — Page structure
- `style.css` — Layout, colors, responsive styles, print styles
- `script.js` — Validation and calculations

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser.
3. Enter the name and marks, then click **Calculate result**.

No installation is required.

## Grade rules
| Percentage | Grade |
| --- | --- |
| 90–100 | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| 50–59.99 | D |
| Below 50 | F |

A student passes only if each subject mark is at least 35. These are sample rules; change them in `script.js` to match your college's rules.

## Upload to GitHub
1. Create a repository at https://github.com/new.
2. Name it `student-marks-calculator-web`.
3. Choose **Add file → Upload files**.
4. Extract this ZIP and upload `index.html`, `style.css`, `script.js`, `README.md`, and `.gitignore`.
5. Commit the changes.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Choose **Pages**.
3. Under build and deployment, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for the published site link to appear on the Pages screen.
